# 360T6GS NOR Auto Build

This repository is source-only and CI-first.

It builds NOR-safe firmware variants for Qihoo 360T6GS via GitHub Actions:
- OpenWrt main (NOR profile)
- ImmortalWrt main (NOR profile)
- LEDE main (NOR profile)
- X-WRT main (NOR profile)

Why NOR-only:
- Most 360T6GS upstream builds are for NAND.
- When flashing through Breed on this router, writing a NAND-oriented image can cause bootloop.
- This repo bypasses NAND and uses SPI NOR layout (`jedec,spi-nor`) to match the Breed flashing path.

## Repository layout

- `mt7621_qihoo_360t6gs.dts`: custom NOR DTS used by the NOR build variant
- `scripts/apply-t6gs-nor.sh`: applies NOR DTS + image recipe patch into upstream source
- `.github/workflows/build-360t6gs-all-wrt.yml`: matrix workflow that builds NOR variants

## Build on GitHub Actions

1. Push this repo to your GitHub account.
2. Open the **Actions** tab.
3. Select **Build 360T6GS NOR WRT**.
4. Click **Run workflow**.
5. Wait for all matrix jobs to finish.
6. Download artifacts from each job.

Each artifact contains files from `bin/targets/ramips/mt7621/` for that variant.

Current artifact job names:
- `openwrt-main-nor`
- `immortalwrt-main-nor`
- `lede-main-nor`
- `x-wrt-main-nor`
- `lienol-main-nor`

## NOR flash usage note

The NOR variant is intended for routers flashed through Breed with NOR layout.

Typical Breed flash setting for this profile:
- layout: `public 0x50000`

## Why no firmware `.bin` is stored here

Binary outputs are intentionally excluded to keep this repository clean and reproducible.
All firmware is generated by CI and downloaded from workflow artifacts.
